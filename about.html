About this site

A small project with a practical purpose

This website introduces web development fundamentals through a set of connected, accessible pages.

Project goals

  • Explain the roles of HTML and CSS with beginner-friendly examples.
  • Practice consistent navigation and a shared external stylesheet.
  • Use headings, lists, an image, and a data table in context.
  • Keep the layout readable on both wide and narrow screens.

Class project

This website was created for the IT 3203 web development class project. Visit the IT 3203 class website.

How to use the site

Use the same menu at the top of every page to move between topics. Start at the homepage, review the key concepts, then continue with the links in References.

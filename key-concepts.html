Seven concepts to carry forward

These ideas connect page structure, visual design, and inclusive access.

  1. HTML describes content

    Use elements to express what content is, not just how you want it to look.

  2. Semantic structure matters

    Meaningful landmarks and heading order help people and tools understand a page.

  3. CSS controls presentation

    Stylesheets define visual details such as color, typography, spacing, and layout.

  4. Selectors target elements

    Type, class, and ID selectors connect CSS rules to parts of a document.

  5. The cascade resolves conflicts

    Specificity and source order help determine which matching declaration applies.

  6. Responsive layouts are flexible

    Grid, Flexbox, and adaptable sizing help a page work across viewport sizes.

  7. Accessibility belongs at the start

    Descriptive links, text alternatives, readable contrast, and keyboard access benefit everyone.

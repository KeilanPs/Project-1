Topic 01

HTML: give content meaning

HTML (HyperText Markup Language) describes the structure of a web page. Its elements tell browsers and assistive technologies what each piece of content is.

Anatomy of an HTML element

Most elements use an opening tag, content, and a closing tag. For example, a paragraph is written as <p>A short paragraph.</p>. Some elements, such as images, do not wrap text and are written differently.

<h1>A page heading</h1>
<p>A paragraph that explains the topic.</p>
<img src="photo.jpg" alt="A descriptive text alternative">

Attributes provide extra information. The src attribute identifies an image file, while alt supplies a text alternative describing its purpose.

Build a useful document outline

  • Use one clear <h1> to identify the page's main subject.
  • Organize sections with headings in a meaningful order.
  • Use lists for related items, and tables only for data with relationships.
  • Choose semantic elements such as <nav>, <main>, and <footer> when they fit.

Good markup is more than appearance

Semantic HTML helps people navigate with assistive technology, makes documents easier to maintain, and gives browsers useful information about the content.

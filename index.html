Start with HTML

Welcome to web development

Web development is the practice of creating websites and applications for the internet. A web page begins with content and structure, then gains visual style and interactive behavior. This guide focuses on the first two foundations: HTML and CSS.

Key terms

Quick definitions for getting started
TermMeaning
HTMLThe markup language used to organize and describe web content.
CSSThe style-sheet language used to control how web content looks and is arranged.
ElementA piece of a page, usually defined by an HTML start tag and end tag.
SelectorA pattern in CSS that identifies which HTML elements a rule styles.
Responsive designAn approach that adapts a layout to different screen sizes and devices.

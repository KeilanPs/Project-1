Topic 01

HTML: give content meaning

HTML (HyperText Markup Language) describes the structure of a web page. Its elements tell browsers and assistive technologies what each piece of content is. Good markup makes information easier to navigate, understand, and maintain.

Anatomy of an HTML element

Most elements use an opening tag, content, and a closing tag. For example, a paragraph is written as <p>A short paragraph.</p>. Some elements, such as images, do not wrap text and are written differently.

<h1>A page heading</h1>
<p>A paragraph that explains the topic.</p>
<img src="photo.jpg" alt="A descriptive text alternative">

Attributes provide extra information. The src attribute identifies an image file, while alt supplies a text alternative describing its purpose.

Start with a meaningful document

A document's outline and landmarks help people scan a page and help software identify its regions. Use headings to introduce sections, <main> for the primary content, and <nav> for groups of navigation links. A heading level should reflect the content hierarchy rather than its visual size.

<main>
  <h1>A page about gardens</h1>
  <section aria-labelledby="herbs-heading">
    <h2 id="herbs-heading">Growing herbs</h2>
    <p>Choose a sunny place and well-drained soil.</p>
  </section>
</main>

A section with a heading gives related content a clear name.

Build a useful document outline

  • Use one clear <h1> to identify the page's main subject.
  • Organize sections with headings in a meaningful order.
  • Use lists for related items, and tables only for data with relationships.
  • Choose semantic elements such as <nav>, <main>, and <footer> when they fit.
  • Give form controls visible, programmatically associated labels.
  • Use descriptive link text so the destination makes sense out of context.

Choose native elements first

A real button, link, heading, or form control already has behavior and meaning that browsers and assistive technologies understand. Prefer the appropriate HTML element over recreating it with generic containers.

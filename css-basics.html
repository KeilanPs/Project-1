Topic 02

CSS: make a page clear and inviting

CSS (Cascading Style Sheets) controls presentation: colors, typography, spacing, borders, and the layout of HTML elements.

Rules, selectors, and declarations

A CSS rule starts with a selector, followed by declarations inside braces. Each declaration pairs a property with a value.

p {
  color: #334155;
  line-height: 1.7;
}

This rule selects every paragraph and changes its text color and line spacing. An external stylesheet keeps presentation separate from the page's content.

Common selector types

  • Type selector: h1 selects every level-one heading.
  • Class selector: .card selects elements whose class includes “card”.
  • ID selector: #main-content selects the element with that unique ID.

Use classes for reusable styling and reserve IDs for unique page landmarks or fragment links.

Layout that adapts

Flexbox is useful for arranging items in one direction, such as a navigation row. CSS Grid works well for two-dimensional layouts. A responsive design can change its layout as the available space changes.

These three roles work together: HTML provides the structure, CSS adds the style, and responsive layout adapts the page to different screen sizes.

Padding creates space inside an element; margin creates space around it. Borders, color, and type choices can reinforce hierarchy without making content harder to read.

Keep the cascade in mind

When multiple rules match the same element, CSS resolves conflicts using origin, importance, specificity, and source order. Prefer clear, modestly specific selectors.

# Web Development Fundamentals

A six-page introductory website about the building blocks of the web. The site uses plain HTML and one shared CSS file, so it can be hosted as a static site on GitHub Pages.

## Pages

- `index.html` — introduction, table of contents, and key terms
- `html-basics.html` — HTML structure and semantic markup
- `css-basics.html` — CSS rules, selectors, and layout
- `key-concepts.html` — seven important concepts
- `references.html` — learning resources
- `about.html` — project information and the class-project note

## Preview locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish with GitHub Pages

1. Push the project files to the repository's default branch.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish and use the URL shown in the Pages settings.

The About page links to the IT 3203 class site. The public URL for this project is assigned by GitHub Pages after publishing.

## Validate

Check each HTML page with the [W3C HTML Checker](https://validator.w3.org/). The site uses only static HTML, CSS, and a local SVG illustration.

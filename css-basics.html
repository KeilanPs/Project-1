Topic 02

CSS: make a page clear and inviting

CSS (Cascading Style Sheets) controls presentation: colors, typography, spacing, borders, and the layout of HTML elements. A shared stylesheet makes a site's visual rules easier to reuse and update.

Rules, selectors, and declarations

A CSS rule starts with a selector, followed by declarations inside braces. Each declaration pairs a property with a value.

p {
  color: #334155;
  line-height: 1.7;
}

This rule selects every paragraph and changes its text color and line spacing. An external stylesheet keeps presentation separate from the page's content.

CSS properties are inherited selectively: text color and font choices commonly pass to descendants, while margins and borders usually do not. This makes reusable defaults possible without relying on inline styles.

Common selector types

  • Type selector: h1 selects every level-one heading.
  • Class selector: .card selects elements whose class includes “card”.
  • ID selector: #main-content selects the element with that unique ID.

Use classes for reusable styling and reserve IDs for unique page landmarks or fragment links.

When rules conflict, the cascade considers origin and importance, selector specificity, and then source order. Keeping selectors predictable avoids having to override earlier rules repeatedly.

Understand the box model

Each element is laid out as a box. Content sits inside padding; the border wraps the padding; and margin creates space outside the border. The border-box sizing rule includes padding and border in the declared width, which makes responsive sizing easier to reason about.

* {
  box-sizing: border-box;
}

.card {
  width: min(100%, 32rem);
  padding: 1.25rem;
  border: 1px solid #d3e0e5;
}

Layout that adapts

Flexbox is useful for arranging items in one direction, such as a navigation row. CSS Grid works well for two-dimensional layouts. A responsive design can change its layout as the available space changes.

These three roles work together: HTML provides the structure, CSS adds the style, and responsive layout adapts the page to different screen sizes.

Padding creates space inside an element; margin creates space around it. Borders, color, and type choices can reinforce hierarchy without making content harder to read.

/* Let the content reflow instead of forcing a fixed column width. */
.article-layout {
  display: grid;
  grid-template-columns: minmax(0, 2fr) minmax(14rem, 1fr);
  gap: 1.5rem;
}

@media (max-width: 700px) {
  .article-layout {
    grid-template-columns: 1fr;
  }
}

A media query can change the grid when the available viewport becomes narrow.

Keep the cascade in mind

Prefer clear, modestly specific selectors and a small set of design tokens for shared colors and spacing. Use relative sizing where appropriate, and check contrast and focus visibility as part of the design—not as a final patch.
